# 📊 Customer Segmentation Dashboard

## 📌 Project Overview
This project focuses on **Customer Segmentation Analysis**. Raw transactional and demographic data from Microsoft Excel was processed and modeled into an interactive **Power BI Dashboard** to group customers, analyze purchasing behavior, and identify high-value customer segments.

## 🔍 Comprehensive Key Insights & Features

1. **Demographic Profiling & Distribution:**
   * Segmented customers across key variables including income brackets, occupation, region, and marital status.
   * Evaluated how household attributes impact overall spending patterns and product preferences.

2. **Purchasing Behavior & Value Clustering:**
   * Analyzed transaction frequency, average order value, and total revenue contribution per segment.
   * Highlighted core differences between high-frequency buyers and high-ticket single-purchase customers.

3. **Strategic Marketing & Business Impact:**
   * Identified high-value customer clusters to enable personalized, high-ROI marketing strategies.
   * Uncovered underperforming customer segments to guide tailored promotional offers and loyalty programs.

## 🚀 How to View and Use the Project

2. **Raw Data Inspection:** Open `Data.xlsx` to review the underlying schema, raw attributes, and transaction history.
